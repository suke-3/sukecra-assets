# sukecra-assets

Minecraft サーバー **すけクラ** の、見た目のデータ（リソースパック）を配るための置き場です。

## なぜ公開しているのか

Minecraft は、サーバーが絵そのものを配る作りになっていません。
**「この住所に置いてあるから取りに行って」** とだけ伝え、
実際の受け取りは**参加者それぞれのパソコン**が行います。

そのため、**誰でも取りに行ける場所に置く必要があります**。

## 中身

| | |
|---|---|
| `sukecra-food` | 参加者が作ったオリジナル料理の絵とモデル |

今後、建築ブロックなどの見た目データも同じ形で追加されます。

**ダウンロードは [Releases](../../releases) から。**

## 入っていないもの

サーバーの設定・ワールド・プログラムは**一切入っていません**。
このリポジトリにあるのは**見た目のデータだけ**です。

## 絵について

料理の絵は、すけクラの参加者が描いたものです。
**すけクラの外での利用はご遠慮ください。**
